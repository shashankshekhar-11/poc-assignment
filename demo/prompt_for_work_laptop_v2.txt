Build a mock HTML/CSS/JS UI for a "Localization Agent — CSL Workbench" tool. This is a MOCK for stakeholder sign-off, not production code — keep it simple. This is v2 of a previous mock — two things changed based on stakeholder feedback: (1) the data structure is now hierarchical, not flat, and (2) the visual style must feel like SAP Fiori/UI5, not a generic custom design.

STRICT CONSTRAINTS:
- Exactly 3 files: index.html, styles.css, app.js. Do NOT split into more files (no component system, no separate files per feature/step, no state management library). A previous over-engineered 10-file version broke from a single filename typo and was hard to debug — stay simple.
- Vanilla JS only, no frameworks, no build step. Must run by just opening index.html in a browser (or via Live Server).
- Use plain `for` loops instead of `.forEach()` on NodeLists from querySelectorAll, for older browser compatibility.
- Use CSS flexbox for the main layout (not CSS Grid) for broad compatibility.
- Include the SheetJS library via CDN for a REAL Excel export: `https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js`

VISUAL DESIGN — SAP Fiori / UI5 style (this replaced an earlier "ledger" aesthetic — go full Fiori this time):
- Background: light gray #F7F7F7 for content area.
- Shell bar (top header): dark blue-gray #354A5E background, white text, SAP-style — includes an app title and a country selector on the right.
- Primary action color: SAP Fiori blue #0070F2 (buttons, active states, links).
- Semantic colors: success/positive #257A3E, warning #E76500, error #B00.
- Font: 'Arial', 'Helvetica Neue', sans-serif (SAP's real font "72" isn't on Google Fonts, so use a clean system sans-serif stack as the closest free substitute). No serif fonts anywhere — Fiori is fully sans-serif.
- Cards/panels: white background, 1px solid #E5E5E5 border, very subtle shadow (0 0 0.125rem rgba(0,0,0,0.1)), small border-radius (0.25rem max — Fiori is not heavily rounded).
- Tables: compact row height (~2.75rem), thin #E5E5E5 row dividers, header row with light gray #FAFAFA background and bold small-caps-style labels (not heavy teal blocks like before).
- Left navigation: icon + label list items in a white sidebar, NOT numbered circles/stepper — use simple SAP-style nav list items with a colored left border (3px, blue) on the active item, and a light blue background tint (#E8F1FD) on hover/active. Group with small uppercase section labels (Prepare / Orchestrate / Review & Export) same as before, but styled as Fiori list group headers (small, gray, letter-spaced).
- Buttons: Fiori-style — primary button is solid #0070F2 with white text, slightly rounded corners (0.25rem), no all-caps. Secondary button is white with a 1px #0070F2 border and blue text (SAP's "ghost/transparent" button style).
- Overall feel: flat, clean, information-dense, professional enterprise software — NOT a warm/editorial "consultant's ledger" look. Minimal decorative elements.

LAYOUT:
- Header (shell bar): app title "Localization Agent — CSL Workbench", subtitle "Country-Specific Localization · category-to-process mapping and requirement generation" in a lighter/smaller weight, and a country dropdown top-right (Austria, France, Italy, UK, USA, India — India is the reference example for the sample data, see below).
- Left sidebar nav (260px), grouped into three labeled sections styled as Fiori nav list groups:
  - "PREPARE": (1) Localization Categories, (2) Category → L3 Mapping, (3) Modify Mapping
  - "ORCHESTRATE": (4) Send to Agent
  - "REVIEW & EXPORT": (5) CSL Data Review
- Right main content: one panel per step (only active one visible via a `goTo(step)` function), each inside a white Fiori-style card, with Back/Continue buttons at the bottom.

Country → Localization Category → Localization Sub-category → (one or more) Localization Short Description rows, each mapped to its own "iCaptivate L3 Process".

Use "iCaptivate L3 Process" as the exact column label — not "L3 Business Process".

STEP CONTENT (same 5-step flow as before, adapted to the new hierarchy):

Step 3 — Modify Mapping: same hierarchical table as Step 2, but editable — Category, Sub-category, and Description cells are `contenteditable="true"`, iCaptivate L3 Process is a `<select>` dropdown (populate options from the distinct L3 values used across the dataset). Step 4 — Send to Agent: Fiori card titled "Ready to send" showing selected country and total row count (count of description-level rows, not category count), with a primary "Send to Agent" button.
